## Administración local

Se incluye una mini administración en la carpeta admin para editar y mover series entre colecciones.

### Cómo usarla

1. Desde la raíz del proyecto, ejecuta:
   `python3 scripts/admin_server.py`
2. Abre http://127.0.0.1:8000/admin/
3. Los cambios se guardan directamente en los JSON de la carpeta data.

La interfaz usa Vue.js y comparte el estilo visual del proyecto original.
